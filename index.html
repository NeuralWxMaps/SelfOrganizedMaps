Self-Organized Maps

Meteorologists have long recognized that similar weather patterns can produce similar types of weather on a regional scale, especially during more significant weather events. But quantifying the similarity of weather patterns has always been a challenge. Collecting a number of case studies related to a particular set of weather events, like Atlantic Bomb Cyclogenesis, Pacific Atmospheric River Rainfall episodes, or Four Corner Upper Level Lows, shows the similarities that meteorologists focus on when forecasting future extreme weather events. But a collection of case studies gives little indication of how often a certain pattern has developed, or what its climatological probability might be. An organized catalog, or atlas, of historical weather patterns does not seem to exist, other than the chronological record in datasets like the NCAR Reanalysis. This project will set out to propose a possible catalog of weather patterns, and look into some possible uses for such a weather pattern catalog.

My proposal is to use a partial implementation of Self-Organized Maps, intoduced by Teuvo Kohonen in the late 1980s. Using the idea that a weather map can be represented as an array of grid points across a selected domain, the arrays in a training dataset can be compared to a neural network of arrays, whose size is equal to the number of grid points in the domain. Using the 2.5 degree by 2.5 degree dataset in the NCAR Reanalysis, I chose a domain covering the northeast Pacific and almost all of North America. This domain was a 23-by-45 grid, meaning that the Self-Organized Map, or Neural Network, would have 1035 points, or solenoids.

A simplified example can show how the training of a Self-Organized Map works. Start with a 5-by-5 pattern(array) and a neural network of 25 arrays, initialized with values of zero.

Calculate the sum of differences squared between training array and the arrays of each node of the neural network, looking for the node that has the lowest value. The node in the neural network with the lowest value will be chosen as the winning node. In this case, all of the differences are equal, so node 0 is chosen as the winning node.

Next, the winning node of the neural network and its adjacent neighbors are adjusted toward the training pattern according to some simple rules. In this example, the winning node is adjusted half way toward the training array. The directly adjacent nodes are adjusted one-quarter of the way toward the training array, and the diagonally adjacent node is adjusted one-eighth of the way toward the training array. The adjusted network becomes the neural network that will be used in the next iteration of the algorithm.

For the next iteration, calculate differences between a new pattern and each of the nodes in the neural network, select the winning node, and then adjust the network based on the rules.

One more iteration will show a node other than Node 0 being the winning node, allowing the neural network(self-organized map) to begin expanding.

As more patterns are cycled through the algorithm, more and more nodes in the self-organized map will be defined, and unique patterns will emerge. Since only neighboring nodes are affected on successive iterations, much of the neural network remains unchanged each time, while local adjustments are applied.

With a 23 by 45 neural network established, a training dataset stretching from 1951 through 2025 was run through the algorithm. For each individual weather pattern, its array was compared to the array of solenoids to find the closest pattern, by locating the smallest sum of differences squared. Then the matchng solenoid and 48 of the closest solenoids were adjusted toward the latest training array, with the adjustment diminishing as the euclidean distance from the matching solenoid increases. In the first epoch of training, I used every 9th time period of the year for every third year staring with 1951. In the second epoch, every 7th time period of the year was used for every third year starting in 1952. And the third epoch involved every 5th time period of every third year, starting with 1953. In this manner, 16,500 uniqe weather patterns, spanning 75 years were run through the training algorithm to define the 1035 nodes of the neural network.

The first parameter that I worked with was the 500 hPa geopotential height field. In order to normalize the data, and remove the seasonal variation in 500 hPa geopotential heights, the height value of the center grid point was subtracted from each grid point of the array of data as it was run through the algorithm. By plotting the resulting array of weather patterns, any node's neighboring nodes will be similar, but not identical to the first node. Moving across the the rows and columns of the neural network of weather patterns shows increasing variety as euclidean distance increases. After defining all of the arrays in the neural network, it will be possible to assign the value of the closest matching node to any weather pattern that is desired.
